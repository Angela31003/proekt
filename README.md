# 📍 Tourist Guide Skopje

##  Опис на апликацијата
Tourist Guide Skopje е мобилна апликација за туристи кои го посетуваат градот Скопје. Апликацијата им овозможува на корисниците да истражуваат значајни локации, да добијат информации за местата и да ги зачуваат своите патувања.

---

##  Клучни функционалности
✔️ **Најава и регистрација** – Корисниците можат да креираат профил и да се најават во апликацијата.  
✔️ **Главна страница (HomeActivity)** – Приказ на познати места во Скопје со слики и описи.  
✔️ **Избор на место со Radio Buttons** – Корисниците можат да изберат место и да ја видат неговата слика.  
✔️ **Приказ на детали (PlaceDetailActivity)** – Прикажување на дополнителен опис за избраното место.  
✔️ **Внес на посакувана дестинација (MapActivity)** – Користење на Google Maps API за поставување почетна локација и крајна дестинација.  
✔️ **Автоматско добивање на тековна локација** – Апликацијата ја одредува почетната локација преку GPS.  
✔️ **Зачувување на патувања** – Избраните дестинации се зачувуваат во „Мои патувања“ (RecyclerView).  
✔️ **Action Bar** – Вклучено мени за подесувања и навигација.  
✔️ **Поддршка за Portrait & Landscape** – Во landscape режим, апликацијата користи фрагменти за приказ на слика и опис на ист екран.

## Инсталација и употреба

### **Клонирање на репозиториумот**
```sh
git clone https://github.com/your-repository/tourist-guide-skopje.git
cd tourist-guide-skopje
```

### **Отворање во Android Studio**
1. Отвори **Android Studio**.
2. Кликни `Open` и избери ја папката на проектот.
3. Почекај да се изврши `Gradle Sync`.

### **Поставување на Google Maps API Key**
1. Оди во `AndroidManifest.xml` и додади го API клучот:
```xml
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_API_KEY_HERE" />
```
2. Замени `YOUR_API_KEY_HERE` со вистински API клуч добиен од Google Cloud Console.

###  **Извршување на апликацијата**
- Поврзи Android уред или стартувај емулатор.
- Кликни `Run` (Shift + F10) во Android Studio.
